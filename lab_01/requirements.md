# Lab 01 Requirements

In Lab 01, deploy a software system (for example, WordPress) to a public cloud
provider (for example, AWS), carrying out tasks similar to the following:

- Create a load balancer (ELB).
- Create a MySQL database (RDS).
- Create a network filesystem (EFS).
- Create and attach firewall rules (security groups).
- Create two virtual machines running web servers:
  - Create two virtual machines (EC2).
  - Mount the network filesystem (EFS).
  - Install Apache/Nginx and PHP.
  - Download and extract the latest WordPress release.
  - Configure WordPress to use the created MySQL database (RDS).
  - Start the Apache/Nginx web server.
  - Install the WordPress instance.
  - Access the WordPress instance.
